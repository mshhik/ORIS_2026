Простой чат-сервер на сокетах

Наше сообщение состоит из трёх частей: КОМАНДА + ДЛИНА + ДАННЫЕ.
Заголовок (8 байт): первые 4 байта занимают буквы команды, а следующие 4 байта — это размер текста, превращенный в байты через модуль struct.
Данные: сам текст сообщения, который идет сразу после заголовка.

Список доступных команд:
JOIN — войти в чат и сохранить имя.
TEXT — отправить сообщение всем участникам чата.
LIST — посмотреть список всех, кто сейчас онлайн.
QUIT — выйти из чата и закрыть программу.
